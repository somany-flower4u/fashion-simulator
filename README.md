# 포켓몬 배틀 시뮬레이션 🎮

자바 디자인 패턴을 활용한 포켓몬 배틀 시뮬레이션 게임입니다.

## 📋 프로젝트 개요

플레이어가 6마리의 포켓몬 중 3마리를 선택하여 AI 라이벌과 실시간 배틀을 펼치는 프로젝트입니다.
- **타입 시스템**: 불, 물, 풀, 일반 타입의 상성 구현
- **동적 배틀**: 포켓몬 교체, 스킬 선택 등의 전략적 요소
- **AI 시스템**: 라이벌이 상성을 고려하여 포켓몬 교체 및 스킬 선택

## 🏗️ 프로젝트 구조

### 핵심 클래스

| 클래스 | 설명 |
|--------|------|
| **Main** | 게임 시작점, 메인 루프 관리 |
| **Pokemon** (추상) | 모든 포켓몬의 기본 클래스 (HP, 공격력, 방어력, 속도 등) |
| **FirePokemon** | 불 타입 포켓몬 (리자몽, 부스터) |
| **WaterPokemon** | 물 타입 포켓몬 (거북왕, 무장조) |
| **GrassPokemon** | 풀 타입 포켓몬 (오염독, 리플록) |
| **PokemonFactory** | 팩토리 패턴으로 포켓몬 생성 및 스킬 설정 |
| **Trainer** | 플레이어/라이벌 클래스 (포켓몬 파티 관리) |
| **BattleManager** | 배틀 로직 관리 (턴 시스템, 승패 판정) |
| **Skill** | 포켓몬이 사용할 스킬 (데미지 계산, PP 관리) |
| **Type** | 타입 열거형 (상성 계산) |

### 디자인 패턴

- **Factory Pattern**: `PokemonFactory` - 다양한 포켓몬 객체 생성
- **Strategy Pattern**: `Pokemon` 추상 클래스와 타입별 구체적 클래스
- **Enum Pattern**: `Type` - 타입 관리 및 상성 계산

## 🎮 게임 플레이

### 게임 시작
```
1. 프로그램 실행 → Main.java 실행
2. 포켓몬 도감 로드 (6마리)
3. 플레이어가 3마리 선택
4. AI가 3마리 랜덤 배정
5. 배틀 시작
```

### 배틀 진행
- **턴 제 시스템**: 속도에 따라 행동 순서 결정
- **플레이어 선택지**:
  - 공격: 사용 가능한 스킬 중 선택
  - 교체: 살아있는 포켓몬으로 교체
- **AI 동작**:
  - 포켓몬이 KO되면 자동으로 상성 좋은 포켓몬으로 교체
  - 랜덤으로 스킬 선택

### 승패 판정
- 한 트레이너의 모든 포켓몬이 KO되면 게임 종료
- MVP: 가장 많은 포켓몬을 처치한 포켓몬

## 🛠️ 주요 기능

### 데미지 계산 시스템
```
기본 데미지 = (공격력 / 방어력) × 기술력 × 0.5
최종 데미지 = 기본 데미지 × 타입 상성배율 × 난수(0.85~1.0)
```

### PP (Power Point) 시스템
- 각 스킬마다 일정 횟수 사용 가능
- PP가 0이 되면 해당 스킬 사용 불가
- 배틀 중 회복 불가 (배틀 종료 후 자동 회복)

### 선제 공격 (Priority)
- 일부 스킬(예: 전광석화)은 속도와 무관하게 항상 먼저 실행
- 양쪽 모두 선제 공격을 선택하면 다시 속도 기준으로 판정
