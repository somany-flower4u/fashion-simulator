# 날씨 및 목적 기반 외출 코디네이터 👔

자바 디자인 패턴을 활용한 날씨와 일정에 맞는 최적의 코디를 추천하는 시뮬레이터입니다.

## 📋 프로젝트 개요

매일 아침 날씨와 일정에 맞춰 옷을 고르는 시간을 줄여주는 코디네이터입니다.
- **타겟**: 오늘 어떤 옷을 입어야 할지 고민하는 사람들
- **목적**: 날씨와 일정에 맞는 옷을 추천
- **효율성**: 날씨 확인 / 일정 파악 / 옷 조합 과정을 자동화된 하나의 플로우로 통합
- **생산성**: 날씨 부적합이나 TPO 미스매치로 인한 컨디션 저하 방지

## 🏗️ 프로젝트 구조

### 핵심 클래스

| 클래스 | 설명 |
|--------|------|
| **Main** | 프로그램 시작점, 메인 루프 관리 |
| **ClothingItem** (추상) | 모든 옷 아이템의 기본 클래스 (보온성, 방수성, 격식성, 편안함) |
| **Top** | 상의 카테고리 |
| **Bottom** | 하의 카테고리 |
| **Outer** | 아우터 카테고리 |
| **ClothingFactory** | 팩토리 패턴으로 옷 아이템 생성 및 특성 설정 |
| **Wardrobe** | 사용자 옷장 관리 (상의/하의/아우터 보유) |
| **Outfit** | 코디 세트 (상의+하의+아우터 조합) |
| **OutfitRecommender** | 추천 로직 관리 (상황 입력, 점수 계산, 결과 출력) |
| **ClothingProperty** | 옷 아이템의 특성 (보온/방수/격식/편안 별 별볼너스) |
| **Situation** | 오늘의 상황 객체 (날씨 + 일정 + 기온) |
| **Category** | 카테고리 열거형 (상의/하의/아우터) |
| **Weather** | 날씨 열거형 (맑음, 비, 눈, 추움, 더움, 바람) |
| **Schedule** | 일정 열거형 (정장/회의, 캐주얼 외출, 울동, 데이트) |
| **GameUtils** | 공용 유틸리티 메서드 통합 |
| **RecommendStrategy** (인터페이스) | 추천 알고리즘 전략 |
| **BasicRecommendStrategy** | 기본 추천 전략 구현 (완전 탐색) |

### 디자인 패턴

- **Factory Pattern**: `ClothingFactory` - 다양한 옷 아이템 객체 생성
- **Strategy Pattern**: `RecommendStrategy` 인터페이스 - 추천 알고리즘 로직 분리
- **Enum Pattern**: `Category`, `Weather`, `Schedule` - 카테고리 및 상황 관리

## 🎮 사용 방법

### 실행
```bash
javac *.java
java Main
```

### 추천 진행
1. 프로그램 실행 → Main.java 실행
2. 옷장 로드 (상의 2벌, 하의 2벌, 아우터 2벌)
3. 오늘의 날씨 선택
4. 오늘의 일정 선택
5. 오늘의 기온 입력
6. 최적의 코디 자동 추천 및 적합도 점수 확인

### 추천 결과
- **적합도 점수**: 각 아이템의 능력치 × 상황별 가중치 = 총 적합도
- **점수 구간**:
  - 900점 이상: 🌟 완벽한 코디
  - 700~899점: 👍 훌륭한 코디
  - 500~699점: 😊 묘난한 코디
  - 500점 미만: 🤔 아쉬운 코디

## 👔 옷장 정보

### 상의 (👕)
- **반팔티**: 편안함 특화 - 보온:20, 방수:10, 격식:10, 편안:80
- **셔츠**: 격식 특화 - 보온:30, 방수:20, 격식:70, 편안:50

### 하의 (👖)
- **청바지**: 밸런스형 - 보온:40, 방수:30, 격식:40, 편안:70
- **슬랙스**: 격식 특화 - 보온:35, 방수:25, 격식:80, 편안:50

### 아우터 (🧥)
- **후드집업**: 편안/보온형 - 보온:60, 방수:30, 격식:20, 편안:80
- **트렌치코트**: 격식/방수형 - 보온:50, 방수:60, 격식:80, 편안:40

## 📊 적합도 계산 시스템

```
기본 점수 = 아이템 능력치 × 상황 가중치
총 적합도 = Σ(상의 점수 + 하의 점수 + 아우터 점수) + 특성 별볼너스

[상황별 가중치 예시]
- 보온성: 기온 5℃ 미만 → 2.5배 / 30℃ 이상 → 0.5배
- 방수성: 비 오는 날 → 3.0배
- 격식성: 정장/회의 → 2.5배
- 편안함: 울동 → 3.0배
```
